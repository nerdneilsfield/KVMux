# Synthetic HEVC fixture

`hevc_1080p60.h265` contains 60 synthetic 1920×1080 frames at 60 fps.
It has no camera content or external copyrighted source material.
IDRs at frames 0 and 30 carry VPS/SPS/PPS. There are no B frames.

Generated on Jetson Orin NX, L4T R36.4.7, using NVIDIA nvvideo4linux2:

```sh
gst-launch-1.0 -e videotestsrc num-buffers=60 is-live=true pattern=ball ! video/x-raw,format=I420,width=1920,height=1080,framerate=60/1 ! nvvidconv ! "video/x-raw(memory:NVMM),format=NV12" ! nvv4l2h265enc num-B-Frames=0 insert-sps-pps=true insert-aud=true idrinterval=30 iframeinterval=30 bitrate=8000000 ! filesink location=hevc_1080p60.h265
```

SHA-256: `62a33b9044a17488e204611c59b0a61a16f0ba52c1517afb1c74aef7a0c9fb90`.
Software decoding is suitable for CTest. VideoToolbox decoding is a separate,
explicit native check; this fixture does not prove camera or KVM performance.
